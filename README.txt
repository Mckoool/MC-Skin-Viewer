# Minecraft Skin Viewer

Open `index.html` in a modern browser.

What it does:
- Automatically attempts to open the skin picker when the page loads.
- Accepts a Minecraft skin PNG.
- Displays the player as a real-time 3D Minecraft-compatible model.
- Supports classic and slim/Alex arm models.
- Mouse/touch drag rotates the model.
- Mouse wheel / pinch zooms.
- Right-drag pans.
- Auto-rotate and walking animation controls.
- Drag-and-drop and Ctrl+V image paste are supported.

The viewer uses skinview3d 3.4.2 from jsDelivr. Internet access is required when the page loads the library.
